📊 Weekly Sales Import

Import POS sales data to calculate recommended orders

📋 How to use:
1. Set the week/date of sales
2. Paste your POS data (Scan Code | Description | # Sold) from your POS report
3. Click "Process Sales" to match items
4. Review matches and click "Save to Sheets"
